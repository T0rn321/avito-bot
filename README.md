# Avito → Telegram: мониторинг новых объявлений

Бот проверяет страницы поиска Авито и присылает в Telegram только **новые** объявления
(и снижение цены у уже виденных). Поиски можно менять прямо из Telegram.

## Что нужно один раз

1. **Токен бота.** В Telegram откройте `@BotFather` → `/newbot` → скопируйте токен.
2. **Ваш chat id.** Напишите вашему боту любое сообщение, потом откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id": ...}`.
   Или спросите `@userinfobot`.

## Вариант A: GitHub Actions (без своего железа, бесплатно, 24/7)

Как устроено: расписание GitHub (cron) срабатывает с задержками в десятки минут и бывает
пропускает запуски, поэтому на него завязан только старт. Сам бот работает долго:
одна задача живёт 5 ч 40 мин и проверяет Авито **каждые ~60 секунд**, между проверками
слушает Telegram (команды отвечают мгновенно). В начале задача ставит в очередь следующий
запуск, он стартует сразу после неё, так что перерывов нет. Cron каждые 2 часа лишь страховка.

1. Создайте на GitHub **публичный** репозиторий (в приватном бесплатных минут хватит
   меньше чем на 2 суток работы). В нём будут видны ссылки поисков и id объявлений, токен нет.
2. Загрузите файлы. **Файл `.env` не загружайте** (он в `.gitignore`, но при загрузке через
   сайт игнор не работает), и убедитесь, что папка `.github/workflows/monitor.yml` попала
   в репозиторий (скрытые папки сайт часто пропускает). Надёжнее загружать через `git push`.
3. `Settings → Secrets and variables → Actions → New repository secret`:
   `TG_TOKEN` и `TG_CHAT_ID`.
4. `Settings → Actions → General`: «Allow all actions», в «Workflow permissions» выберите
   «Read and write permissions».
5. Вкладка `Actions` → `avito-monitor` → `Run workflow`. Дальше цепочка продолжает себя сама.
   (Запуск произойдёт и сам при пуше файла workflow.)
6. Через минуту в Telegram придёт «Поиск запомнил…».

### Если workflow «ни разу не запустился сам»

Проверьте по порядку:

- Файл лежит ровно в `.github/workflows/monitor.yml` **в ветке по умолчанию** (cron работает только оттуда).
  Вкладка `Actions` показывает «avito-monitor» слева? Если нет, файл не загрузился.
- `Settings → Actions → General`: действия не отключены. В **форке** расписание выключено по умолчанию,
  нужно нажать «I understand my workflows, go ahead and enable them».
- Вкладка `Actions`: нет ли красной ошибки «Invalid workflow file» (опечатка в YAML).
- Частое расписание `*/10` у GitHub самое проблемное: запуски в «круглые» минуты
  отбрасываются при нагрузке, а у новых и тихих репозиториев ещё и стартуют с большой задержкой.
  Поэтому теперь старт один раз вручную, а дальше цепочка сама.
- Репозиторий без активности 60 дней: GitHub отключает расписание. Бот коммитит состояние при
  новых объявлениях, но если всё же встало, нажмите `Run workflow`.

### Нюансы

- **Главный риск:** Авито часто режет IP облачных серверов, а у GitHub именно такие. Если так,
  бот сам напишет в Telegram «Авито не пускает». Тогда вариант B или прокси.
- Частота: чаще раз в 20 сек бот не проверяет. Если приходят блокировки, поставьте `/interval 180`.
- Если бот когда-то запускали у себя на ПК с тем же токеном, остановите его: два бота,
  читающих одни и те же команды Telegram, мешают друг другу.
- Долгие задачи в Actions допустимы для личного проекта, но это на грани условий GitHub
  (Actions предназначены для сборки и тестов). Держите проект небольшим и личным.

## Вариант B: домашний ПК или старый Android-телефон (IP как у обычного человека)

Домашний или мобильный IP Авито блокирует заметно реже, чем облачный.

```bash
pip install -r requirements.txt
cp .env.example .env      # впишите TG_TOKEN и TG_CHAT_ID
python avito_bot.py --ping   # проверка, придёт «Бот на связи»
python avito_bot.py          # работает, пока запущен (проверка раз в 60 сек, команды мгновенно)
```

**Телефон (Termux):** установите Termux из F-Droid, затем
`pkg install python git`, `pip install -r requirements.txt` (если `curl_cffi` не ставится,
бот сам перейдёт на `requests`), положите файлы, запустите `python avito_bot.py`.
Включите `termux-wake-lock` и отключите оптимизацию батареи для Termux.

## Как менять поиски

Из Telegram (работает в обоих вариантах, ответ приходит сразу):

```
/add Винил | https://www.avito.ru/... | 3000
/list
/del 1
/interval 45     # как часто проверять, секунды (20..3600)
```

Ссылку берите из адресной строки Авито после выбора города, категории и фильтров.
Включите сортировку «по дате», тогда новое всегда сверху.

Или правьте `searches.json`: кроме `name`, `url` есть `min_price`, `max_price`,
`include` (в названии должно быть хоть одно слово) и `exclude` (ни одного).
Один бот ведёт сколько угодно поисков: винил, машины, телефоны.

## Если Авито блокирует

- Сначала увеличьте паузу (`/interval 180` в Telegram или `--interval 180`) и не держите десятки поисков.
- Добавьте прокси: `PROXY_URL` в `.env` или секрет в GitHub. Мобильные или резидентные
  работают лучше датацентровых, но обычно платные.

## Почему не Hugging Face

Бесплатные Spaces засыпают после 48 часов без активности, и IP у них тоже облачный.
Заставлять их не спать через сторонние «пингеры» — костыль, а GitHub Actions проще и ничего не просит.

## Важно

Правила Авито ограничивают автоматический сбор данных. Для личного мониторинга
с редкими запросами риск небольшой, но проект держите именно в таком режиме.
Вёрстка Авито меняется: если бот пишет, что не нашёл объявлений, нужна правка `parse_items`.
